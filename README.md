# 🚀 Crypto Market Tracker

A modern, dark-themed cryptocurrency market tracker built using **HTML, CSS, and Vanilla JavaScript**. It fetches live cryptocurrency market data from the CoinGecko API and provides real-time search, sorting, and market information.

## 🌐 Live Demo

**[View Live Crypto Market Tracker](https://jahnavi-gottam.github.io/Crypto_Market_Tracker/)**

## 📌 Project Overview

Crypto Market Tracker is a lightweight web application designed to display real-time market information for the top 10 cryptocurrencies.

The application provides users with an easy way to monitor cryptocurrency prices, market capitalization, trading volume, and 24-hour price changes through a clean and responsive interface.

## ✨ Features

- **Live Market Data:** Fetches cryptocurrency information from the CoinGecko API.
- **Top 10 Cryptocurrencies:** Displays the top 10 cryptocurrencies based on market ranking.
- **Cryptocurrency Details:** Shows coin icon, name, symbol, current price, market capitalization, and 24-hour trading volume.
- **24-Hour Price Changes:** Displays percentage changes with green and red indicators.
- **Instant Search:** Search and filter cryptocurrencies by name or symbol in real time.
- **Sorting:** Sort cryptocurrency data in ascending or descending order based on market capitalization or 24-hour percentage change.
- **Dual Promise Handling:** Implements API data fetching using both `.then()` and `async/await` approaches.
- **Responsive Dark UI:** Provides a clean, minimalist dark-themed interface with a responsive layout.

## ⚙️ How to Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/jahnavi-gottam/Crypto_Market_Tracker.git
```

**2. Navigate to the project directory**

```bash
cd Crypto_Market_Tracker
```

**3. Open the project**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## 🔗 API Integration

This project uses the **CoinGecko API** to retrieve cryptocurrency market information.

API documentation:

https://docs.coingecko.com/

The application retrieves market information such as:

- Cryptocurrency name and symbol
- Current market price
- Market capitalization
- Total trading volume over 24 hours
- Price percentage change over 24 hours

*Note: API availability and request limits may affect live data fetching.*

## 🚀 Deployment

This project is hosted using **GitHub Pages**.

To deploy your own version:

1. Push the project files to a GitHub repository.
2. Open repository Settings.
3. Navigate to Pages.
4. Select `Deploy from a branch`.
5. Select the `main` branch and `/ (root)` folder.
6. Click Save.

Your website will be published using a GitHub Pages URL.
